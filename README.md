# AURA EDIT 

> **"Your 6-second aura, generated by AI."**  
> A cinematic Phonk & Anime-style vertical video creator that turns short webcam clips or video uploads into high-energy, flattering 6-second aura edits.

---

## 30-Second Pitch

Every social media trend from anime TikTok to Phonk gym edits celebrates the iconic "aura moment": the cinematic desaturation, slow dynamic zoom, rhythmic beat drops, blinding white flashes, and glowing bold typography. 

**AURA EDIT** brings that power to everyone in real-time. A user records a 3-4 second webcam clip. Our offline-capable AI pipeline tracks their face, classifies their subtle facial expression, maps it to an epic anime theme (**DARK**, **GOLD**, or **FIRE**), mats the subject off the background, and composites them into an original procedurally-rendered neon environment with custom 808 bass-drop music.

**Most importantly:** AURA EDIT **never** rates, ranks, or judges looks. Everyone receives an empowering, flattering edit designed to wow live expo audiences in under 15 seconds.

---

## Architecture & How the AI Pipeline Works

The application is cleanly divided into a modular pipeline in `pipeline/`:

```
Input Video (3-4s Clip)
        │
        ▼
[pipeline/frames.py] ────────► Extracts ~12 keyframes, scales to optimal processing resolution
        │
        ▼
[pipeline/face.py] ──────────► MediaPipe FaceDetector (blaze_face_short_range)
        │                      Fallback: OpenCV Haar Cascade -> Frame Center
        │                      Outputs: Zoom center (cx, cy) and best face crop
        │
        ▼
[pipeline/emotion.py] ───────► HuggingFace ViT Classifier (dima806/facial_emotions_image_detection)
        │                      Fallback: trpakov/vit-face-expression
        │                      Emotion -> Style Mapping:
        │                        • Neutral / Sad / Fear   -> DARK   ("AURA +9999")
        │                        • Happy / Surprise       -> GOLD   ("MAIN CHARACTER")
        │                        • Angry / Disgust        -> FIRE   ("NO MERCY MODE")
        │
        ▼
[pipeline/background.py] ────► rembg (u2net ONNX) extracts subject cutout
        │                      Procedural NumPy/OpenCV animated background:
        │                        • Dynamic vertical & radial gradient
        │                        • Film grain noise
        │                        • Animated neon light streaks / speed lines
        │                        • Multi-pass aura glow (tight rim + wide soft bloom)
        │
        ▼
[pipeline/audio.py] ─────────► Scans assets/music/ for custom tracks, or
        │                      Procedurally synthesizes an original 6.0s Phonk beat
        │                      with sliding 808 sub-bass, cowbell melody, trap hats & kicks
        │
        ▼
[pipeline/compose.py] ───────► 144 frames (24 fps, 6.0s vertical HD 720x1280)
                                 • 0.0s - 2.0s: Slow cinematic zoom on face target
                                 • 2.0s - 4.5s: 3-4 white flash cuts, beat drops, shake
                                 • Typography: Dual-layer impact text with glow & pop
                                 • 4.5s - 6.0s: Dramatic freeze-frame with lingering aura
                                 • Encoded to H.264 + AAC MP4 via MoviePy
```

## Benchmarks & Render Times

Tested on a standard laptop CPU:

| Stage | Operation | Time (s) |
|---|---|---|
| **Stage 1** | Background Matting & Compositing (12 keyframes) | ~6.5 - 8.5s |
| **Stage 2** | Audio Preparation / 808 Phonk Synthesizer | ~0.03s |
| **Stage 3** | VFX Animation & Typography Rendering (144 frames) | ~1.3 - 1.8s |
| **Stage 4** | MoviePy H.264 + AAC MP4 Encoding | ~2.0 - 2.6s |
| **Total** | **Full Pipeline Execution** | **~10.5 - 13.5s** *(Target: < 25s)* |

## Setup & Quickstart

### 1. Requirements
- Python 3.10, 3.11, or 3.12 (64-bit)
- Windows / Linux / macOS
- FFmpeg (bundled with MoviePy / system)

### 2. Installation
```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# Install pinned dependencies
pip install -r requirements.txt
```

### 3. Pre-download Models for Offline Mode
To run fully offline at an expo booth without Wi-Fi:
```bash
python download_models.py
```
This pre-caches:
- MediaPipe Face Detector model (`blaze_face_short_range.tflite`)
- OpenCV Haar Cascade XML
- `rembg` u2net model (`~/.u2net/u2net.onnx`)
- Hugging Face emotion classification models (`dima806/facial_emotions_image_detection` & fallback `trpakov/vit-face-expression`)

### 4. Run Smoke Test
Verify the entire pipeline end-to-end on the bundled demo sample:
```bash
python tests/smoke_test.py
```

### 5. Launch the Web Application
```bash
python app.py
```
Open your browser to: **`http://127.0.0.1:7860`**

## Custom Music Support

Drop any `.mp3`, `.wav`, or `.aac` audio files into `assets/music/`:
- If files are present, AURA EDIT randomly selects a track, trims it to 6 seconds, and applies a smooth fade-out.
- If `assets/music/` is empty, AURA EDIT automatically synthesizes an original, punchy 808 bass-drop and phonk beat using pure NumPy math so the demo **always has sound** without relying on copyrighted songs.

---

## Privacy & Safety

- **Zero Look Judging:** The app classifies expressions (smile, intensity, focus) into flattering themes. It never scores, ranks, or evaluates attractiveness.
- **Strict Ephemeral Privacy:** All uploaded videos, intermediate frame cutouts, and temporary audio files are stored in isolated temporary directories and deleted upon processing completion.
- **No Data Retention:** No images or personal data are stored or transmitted to external servers.

---

## Known Limitations & Production Enhancements

1. **Camera Framing:** If the user is seated extremely far from the camera or in near-total darkness, face confidence drops. In this event, the pipeline gracefully falls back to the OpenCV Haar cascade or centers the dynamic zoom on the frame center.
2. **Audio Complexity:** Procedural audio synthesis is mathematically clean and punchy, but custom human-produced phonk tracks dropped into `assets/music/` provide the highest production fidelity.
3. **CPU vs GPU:** On standard laptop CPU, rendering takes ~12-14 seconds for 720x1280. On a dedicated GPU with CUDA enabled, rendering executes in under 4 seconds.
