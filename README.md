## 📖 Overview

Every social media trend from anime TikTok to Phonk gym edits celebrates the iconic **"aura moment"**: cinematic desaturation, slow dynamic zoom, rhythmic beat drops, blinding white flashes, glowing neon contours, and bold typography.

**AURA EDIT** brings this capability to any device in real-time. Whether from a 3-4 second webcam recording or an uploaded video:
1. **Tracks Face & Focal Point:** Accurately centers the zoom on the subject's face using MediaPipe BlazeFace.
2. **Analyzes Expression:** Evaluates emotional valence using a Vision Transformer (ViT) and automatically selects a matching anime theme (**DARK**, **GOLD**, or **FIRE**).
3. **Mattes Background:** Extracts high-fidelity foreground cutouts using U²-Net ONNX neural segmentation.
4. **Composites Neon Environment:** Renders dynamic procedural gradients, anime speed lines, film grain, and multi-pass aura bloom.
5. **Generates Phonk Beat:** Produces a punchy, sliding 808 bass drop and cowbell beat using NumPy/SciPy procedural audio synthesis (or mixes bundled music).
6. **Exports Vertical HD:** Encodes a 9:16 vertical HD MP4 (720×1280 @ 24 FPS) in ~10–13 seconds on standard CPU.

> 🛡️ **Safety & Privacy First:** AURA EDIT **never** rates, scores, or judges physical appearance. All expressions are mapped to empowering, positive aesthetic edits. All media processing happens locally, with zero telemetry or cloud dependencies.

## 🧠 Architecture & How It Works

The AI pipeline is designed as an offline-capable, modular execution graph located in `pipeline/`:

```
                    ┌─────────────────────────┐
                    │  Input Video / Webcam   │
                    │      (3-4s Clip)        │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │   pipeline/frames.py    │
                    │   Extract Keyframes     │
                    └────────────┬────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
     ┌───────────────────────┐       ┌───────────────────────┐
     │   pipeline/face.py    │       │  pipeline/emotion.py  │
     │  MediaPipe BlazeFace  │       │ Hugging Face ViT Clf  │
     │  Zoom Target (cx, cy) │       │ Expression -> Theme   │
     └───────────┬───────────┘       └───────────┬───────────┘
                 │                               │
                 └───────────────┬───────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │  pipeline/background.py │
                    │ • U²-Net Matting (rembg)│
                    │ • Neon Shaders & Glow   │
                    │ • Anime Speed Lines     │
                    └────────────┬────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
     ┌───────────────────────┐       ┌───────────────────────┐
     │   pipeline/audio.py   │       │   pipeline/styles.py  │
     │  Procedural 808 Phonk │       │ Theme Config, Colors, │
     │  or assets/music/ wav │       │ Vignette, Text Layers │
     └───────────┬───────────┘       └───────────┬───────────┘
                 │                               │
                 └───────────────┬───────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │   pipeline/compose.py   │
                    │ 144 Frames Vertical HD  │
                    │ Dynamic Zoom + Flashes  │
                    │ MoviePy H.264/AAC MP4   │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │  Final 6s Aura Video    │
                    └─────────────────────────┘
```

### Module Breakdown

| Module | Core Technology | Function |
|---|---|---|
| [`pipeline/frames.py`](file:///e:/Aura%20Edit/pipeline/frames.py) | OpenCV (`cv2`) | Extracts ~12 evenly distributed keyframes, calculates native aspect ratios, and rescales frames to optimal processing bounds. |
| [`pipeline/face.py`](file:///e:/Aura%20Edit/pipeline/face.py) | MediaPipe BlazeFace + OpenCV Haar Cascade | Detects face bounding boxes across keyframes, averages coordinates to establish a smooth zoom focal anchor `(cx, cy)`, and crops the primary face. |
| [`pipeline/emotion.py`](file:///e:/Aura%20Edit/pipeline/emotion.py) | Hugging Face Transformers (`dima806/facial_emotions_image_detection`) | Analyzes facial emotion on the extracted face crop. Maps neutral/focused emotions to **DARK**, happy/surprised to **GOLD**, and angry/intense to **FIRE**. |
| [`pipeline/styles.py`](file:///e:/Aura%20Edit/pipeline/styles.py) | Python Configuration Engine | Stores palette definitions, glow radii, blur passes, flash sequences, vignette strength, and typography presets for each theme. |
| [`pipeline/background.py`](file:///e:/Aura%20Edit/pipeline/background.py) | `rembg` (U²-Net ONNX) + NumPy | Extracts alpha matte of the subject, synthesizes a procedural animated neon background gradient, overlays speed lines, and applies dual-layer Gaussian aura glow. |
| [`pipeline/audio.py`](file:///e:/Aura%20Edit/pipeline/audio.py) | NumPy + SciPy | Checks `assets/music/` for user-supplied audio tracks. If empty, mathematically synthesizes a 6-second Phonk beat with sliding 808 sub-bass, cowbell melody, trap hats, and kicks. |
| [`pipeline/compose.py`](file:///e:/Aura%20Edit/pipeline/compose.py) | MoviePy + Pillow + OpenCV | Generates 144 frames (24 FPS, 6.0s) at 720×1280. Applies progressive dynamic zoom, 3–4 synchronized white flash frames, camera shake, dual-layer glow typography, and encodes final MP4. |
| [`app.py`](file:///e:/Aura%20Edit/app.py) | Gradio 6 | Dark-themed, responsive web UI with one-click demo loading, webcam recording, file upload, manual style overrides, and live video previews. |

## 🚀 Step-by-Step Installation & Quickstart

Follow these instructions to set up and run AURA EDIT on your machine.

### Prerequisites
- **Operating System:** Windows 10/11, macOS, or Linux
- **Python:** Version `3.10`, `3.11`, or `3.12` (64-bit recommended)
- **Git:** Installed on your system
- **Hardware:** Works on any standard dual-core/quad-core CPU. GPU is optional (CPU execution is fully optimized).

---

### Step 1: Clone the Repository
```bash
git clone https://github.com/ashish-sharma-1225/AURA-VIDEO-EDITOR.git
cd AURA-VIDEO-EDITOR
```

---

### Step 2: Create a Virtual Environment

#### On Windows (PowerShell):
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```
*(If PowerShell gives an execution policy error, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` first).*

#### On Windows (Command Prompt `cmd`):
```cmd
python -m venv .venv
.venv\Scripts\activate.bat
```

#### On macOS / Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

---

### Step 3: Install Dependencies
Install all required libraries using pip:
```bash
pip install -r requirements.txt
```

> **Note on PyTorch:** `requirements.txt` installs the lightweight CPU version of PyTorch (`torch` + `torchvision`), keeping the download size minimal and avoiding heavy CUDA dependencies.

---

### Step 4: Pre-download AI Models (For Offline Execution)
Download and cache all AI weights locally in one command:
```bash
python download_models.py
```
This script downloads:
- **MediaPipe BlazeFace** short-range face detection model (`assets/models/blaze_face_short_range.tflite`)
- **OpenCV Haar Cascade** frontal face XML (`assets/models/haarcascade_frontalface_default.xml`)
- **Rembg U²-Net** background matting model (`~/.u2net/u2net.onnx`)
- **Hugging Face ViT** emotion classification weights (`dima806/facial_emotions_image_detection`)

---

### Step 5: Verify with the Smoke Test
Verify the entire pipeline end-to-end on the bundled demo sample:
```bash
python tests/smoke_test.py
```
If configured properly, you will see `[ALL INTEGRATION TESTS PASSED]` and a confirmation of output video dimensions (`720x1280`), audio track, and render time.

---

### Step 6: Launch the Web Application
Start the local web server:
```bash
python app.py
```

Once started, open your web browser and navigate to:
```
http://127.0.0.1:7860
```

1. Click **"Load Demo Sample"** to try the bundled portrait video, or upload/record your own 3–4 second video.
2. Leave Style Mode on **"Auto"** to let AI detect your aura, or manually pick **Dark**, **Gold**, or **Fire**.
3. Click **"Generate Aura Edit"**. In ~12 seconds, your 6-second vertical video will be ready to watch and download!

## ⚡ Offline Mode (Air-Gapped Mode)

AURA EDIT is engineered to run seamlessly at live events, hackathons, and expo booths without relying on an active internet connection.

Once you have run `python download_models.py`, you can test strict offline execution by setting the offline flags:

#### Windows PowerShell:
```powershell
$env:TRANSFORMERS_OFFLINE="1"
$env:HF_HUB_OFFLINE="1"
python app.py
```

#### Linux / macOS:
```bash
TRANSFORMERS_OFFLINE=1 HF_HUB_OFFLINE=1 python app.py
```

## 🎵 Custom Music Support

AURA EDIT features a dual-mode audio engine:

1. **Custom Music:** Drop any `.mp3`, `.wav`, or `.aac` audio files into the `assets/music/` folder. The engine will randomly select a track, trim it to 6.0 seconds, and master it with a clean volume fade-out.
2. **Procedural Phonk Synthesizer:** If `assets/music/` contains no audio files, AURA EDIT's math synthesizer automatically creates an original 6.0-second 808 beat using NumPy & SciPy:
   - Punchy kick drum transients
   - Sliding 808 sub-bass waveform
   - Resonant phonk cowbell arpeggio
   - Crisp trap hi-hat rolls

## 🔒 Privacy, Safety & Ethics

- **No Appearance Scoring:** AURA EDIT never ranks or evaluates physical traits or beauty. Expressions map exclusively to empowering themes.
- **Strict Ephemeral Processing:** Uploaded videos, temporary frame cutouts, and rendered audio buffers exist only in memory or temporary directories and are removed immediately after processing.
- **Local Execution:** No frames or personal identifiers are uploaded to external APIs or remote servers.
