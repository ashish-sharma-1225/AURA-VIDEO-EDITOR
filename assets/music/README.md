# Music Directory

Drop any `.mp3`, `.wav`, or `.aac` audio files into this folder to use them as custom background tracks for your Aura Edits.

### How it works:
1. When generating a video, AURA EDIT randomly selects a track from this directory.
2. The track is automatically trimmed to 6 seconds and mastered with a smooth fade-out.
3. If this directory contains no audio files, AURA EDIT automatically synthesizes an original, punchy 808 bass-drop and phonk-style beat using NumPy and SciPy.
4. **Note:** Please ensure any audio added is royalty-free and copyright compliant for your exhibitions and demos.
